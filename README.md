# Слайд-учёт

Трекер заданий по инфографике: этапы утверждения дизайна и обложки, серии артикулов, резерв готовых слайдов, недельный отчёт для рабочего чата, импорт ТЗ из Excel.

Приложение открывается по адресу https://annkka3.github.io/slide-uchet/ и ставится на домашний экран телефона как обычное приложение. После первого открытия работает без интернета.

## Как устроено

- `index.html` — всё приложение: вёрстка, стили и логика.
- `store.js` — вход по почте и паролю и синхронизация через Firebase (Auth + Firestore).
- `config.js` — настройки Firebase. Пока там `null`, данные хранятся только на этом устройстве.
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим и установка на домашний экран.
- `vendor/` — библиотеки Firebase и SheetJS, лежат рядом, чтобы работать без сети.
- `firestore.rules` — правила доступа: каждый пользователь видит только свои данные.
- `backup/` — личные резервные копии, в репозиторий не попадают.

## Подключение синхронизации (один раз)

1. https://console.firebase.google.com → «Создать проект» → имя `slide-uchet`, Google Analytics можно выключить.
2. На главной странице проекта значок `</>` (веб-приложение) → название «Слайд-учёт» → «Зарегистрировать». Скопировать блок `firebaseConfig` и вставить его в `config.js` вместо `null`.
3. Build → Authentication → «Начать» → Sign-in method → Email/Password → включить → сохранить.
4. Build → Firestore Database → «Создать базу данных» → регион `eur3 (Europe)` → рабочий режим. Вкладка «Правила» → вставить содержимое `firestore.rules` → «Опубликовать».
5. Открыть приложение, ввести почту, придумать пароль, нажать «Создать аккаунт».
6. Меню → «Импорт заданий» → выбрать файл резервной копии `.json`, чтобы перенести задания.
7. По желанию: Authentication → Settings → User actions → снять «Enable create (sign-up)», чтобы новые аккаунты больше не создавались.

## Обновление

Изменения в файлах публикуются командой `git push` в ветку `main`, страница обновляется через минуту-две. При смене списка файлов оболочки стоит поднять `VERSION` в `sw.js`.

## Резервные копии

Меню → «Резервная копия в файл» сохраняет все задания и категории в `.json`. Загрузить копию обратно можно через «Импорт заданий».
